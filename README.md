# 世桜サーベイ（口コミ連結版）

yosakurasurvey.vercel.app の各店舗アンケートページを本部管理下に複製し、
送信後に各店のGoogle口コミ投稿画面へ自動でご案内する機能を追加したもの（2026-09-11）。

対象は世桜の9店舗ぶん（index=本店、store2=牛カツ長堀橋、store3=鰻長堀橋、store5=牛カツ富士山、store6=鰻富士山、store7=寿司心斎橋、store8=鰻浅草橋、store9=和牛広島）。
元サイトのstore4.htmlは世桜と無関係の店舗のため複製していない。

- 回答の送信先（GAS・スプレッドシート）は元のまま＝集計への流れは変わらない
- 星の評価に関係なく全員に同じご案内（Googleのレビューゲーティング禁止ポリシーに準拠）
- 各ページ末尾に ?testthanks を付けると、送信せずにお礼画面と口コミ案内を確認できる（自動移動なし）
